# DormirBem 🌙

## 🌟 Sobre o Projeto
Aplicativo web para melhorar a qualidade do sono, utilizando técnicas cientificamente comprovadas.

## 🚀 Funcionalidades
- Diagnóstico personalizado de sono
- Sons terapêuticos
- Técnica de respiração 4-7-8
- Checklist de hábitos noturnos

## 💻 Tecnologias
- HTML5
- JavaScript
- Web Audio API
- Design responsivo

## 🔧 Como Usar
1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
3. Sem necessidade de instalação
