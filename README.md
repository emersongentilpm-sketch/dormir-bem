# DormirBem 🌙

## Descrição
Aplicativo web para melhorar a qualidade do sono

## Funcionalidades
- Diagnóstico de sono
- Sons relaxantes
- Técnica de respiração 4-7-8
- Checklist de hábitos noturnos

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Web Audio API

## Como Usar
1. Clone o repositório
2. Abra index.html no navegador

## Instalação
Não requer instalação, funciona direto no navegador
