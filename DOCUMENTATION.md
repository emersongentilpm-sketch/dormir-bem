# DormirBem - Documentação Técnica

## Tecnologias
- HTML5 puro
- JavaScript nativo
- Web Audio API
- Design responsivo

## Funcionalidades
- Diagnóstico personalizado de sono
- Sons terapêuticos
- Técnica de respiração 4-7-8
- Checklist de hábitos noturnos

## Diferenciais Técnicos
- Processamento de áudio em tempo real
- Animações suaves
- Interface intuitiva
- Armazenamento local de dados
## Compatibilidade de Navegadores
- Chrome (recomendado)
- Firefox
- Safari
- Edge
- Não recomendado para IE

### Requisitos Mínimos
- Navegador com suporte a:
  - HTML5
  - Web Audio API
  - LocalStorage
  - Flexbox/Grid

### Dispositivos Compatíveis
- Desktops
- Tablets
- Smartphones modernos
